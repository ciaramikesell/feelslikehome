# Beta follow-up: property notes guidance

Property Notes remains the single catch-all field for miscellaneous listing
information. HOA details, sewer/water, financing options, recent updates, and
listing terms are **not** new manual fields in this pass; the form names them
only as examples while an empty Notes field is being edited.

Future enrichment candidates, if a reliable source and a separate scoped pass
justify them, are sewer/water, financing incentives, recent updates, and listing
terms. Existing automatic HOA enrichment remains unchanged. None of these
candidates should be inferred from an address or saved as user notes.
